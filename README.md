# Sports Event Manager

A web-based Sports Event Management System developed as a college mini project.

The system provides a single platform for managing sports event registrations, organizing participant information, and handling spectator ticket bookings.

---

## 📌 Project Overview

Currently, sports event registrations are often collected through third-party platforms such as Google Forms, after which the collected data has to be manually managed by the authorities.

This project aims to provide a dedicated platform where:

- Students can register for sports events directly through the website.
- Sports authorities can view and manage participant registrations for their respective sports.
- Spectators can view upcoming events and book tickets.
- Digital tickets can be generated for event entry.
- The system can eventually be deployed online with a cloud-based database.

---

## 🎯 Objectives

- Create a centralized platform for sports event management.
- Replace third-party registration forms with an integrated registration system.
- Store and organize participant information in a database.
- Provide sport-wise access to registration data for authorities.
- Implement a spectator ticket booking system.
- Generate digital tickets for booked events.
- Deploy the complete system online.

---

## 🚀 Project Development Plan

The project is divided into **3 development sprints**.

### Sprint 1 — Registration & Participant Management

**Goal:** Create the registration system and store user information.

Features:

- Student registration form
- Student details collection
- Sport selection
- Form validation
- Database storage
- Sport-wise participant data
- Authority access to registration data

**Expected Output:**

```
Student
   ↓
Registration Form
   ↓
Validation
   ↓
Database
   ↓
Sport Authority
```
## Sprint 2 — Spectator Ticket Booking

Goal: Implement an event ticket booking system.

Features:

Display upcoming sports events
Event details
Ticket availability
Spectator registration
Ticket booking
Booking confirmation
Digital ticket generation
QR-based ticket verification (if implemented)

```
Spectator

Select Event
   ↓
Book Ticket
   ↓
Booking Confirmation
   ↓
Digital Ticket
```
